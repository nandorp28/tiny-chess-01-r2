A chess engine in under 4 KB of Python: 0x88 board, negamax with PVS, transposition table, null-move pruning, late-move reductions, quiescence with check evasions, tapered piece-square evaluation, and a precomputed opening book against the house gauntlet. Fixed 120,000-node budget per move, fully deterministic.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
